# Godot Editor Settings Cleaner
Add a “Remove” option to the context menu in the editor settings.

> [!Tip]
> If you delete the Godot built-in settings, they will be restored when you reload the project.


## Versions Verified to Work (Previous versions are available on the branch):
- 4.7

Since it relies on undocumented internal nodes, it may stop working after an update.
